# 사각-집필

가볍고 서식 없는 원고 집필기입니다. 꾸미기 없이 원고만 쓰고, 다 쓴 원고는 **hwp·hwpx·docx·txt** 로 내보냅니다. 맞춤법 점검이 들어 있습니다.

## 내려받기

[Releases](https://github.com/magammm1009/sagakstory/releases/latest) 에서 내려받습니다.

| 운영체제 | 파일 |
|---|---|
| macOS 13 이상 (Apple 실리콘·인텔 모두) | `Sagak-Jipil_<판>_mac-universal.dmg` |
| Windows | 준비 중 |

`.app.tar.gz` 와 `latest.json` 은 프로그램 안 자동 업데이트용이라 내려받지 않아도 됩니다.

## 설치와 첫 실행

### 맥

1. `Sagak-Jipil_<판>_mac-universal.dmg` 를 열고 '사각-집필'을 '응용 프로그램(Applications)' 폴더로 끌어다 놓습니다.
2. 처음 켜면 "Apple은 '사각-집필'에 악성 코드가 없음을 확인할 수 없습니다" 같은 창이 뜹니다. **[완료]** 를 누르세요(휴지통으로 옮기지 마세요).
3. **시스템 설정 → 개인정보 보호 및 보안**을 열고 아래쪽 '보안'의 "'사각-집필'이(가) 차단되었습니다" 옆 **[그래도 열기]** → 암호 입력 → 다시 뜨는 창에서 **[그래도 열기]**.
4. 이 과정은 처음 한 번뿐입니다. 이후 새 판은 프로그램 안에서 '지금 업데이트'로 받으며 다시 묻지 않습니다.

애플 개발자 서명이 없는 개인 제작 프로그램이라 나오는 절차입니다. macOS 15 부터는 우클릭 '열기'로 넘어가는 방법이 없어졌습니다.

### 윈도우 (준비 중)

윈도우판은 아직 나오지 않았습니다. 나오면 아래처럼 설치합니다.

1. `Sagak-Jipil_<판>_windows-x64-setup.exe` 를 실행합니다.
2. 파란 창 "Windows의 PC 보호"가 뜨면 **[추가 정보]** → **[실행]**.
3. 관리자 권한 없이 내 사용자 계정에 설치됩니다. 이후 새 판은 프로그램 안에서 '지금 업데이트'로 받습니다.

## 원고는 어디에 저장되나요?

원고는 프로그램 안 저장소에 저절로 저장됩니다.

- 맥: `~/Library/WebKit/io.github.magammm1009.sagakstory/`
- 윈도우: `%LOCALAPPDATA%\io.github.magammm1009.sagakstory\EBWebView\`

그리고 **하루 한 번 모든 작품을 `문서/사각-집필/백업` 폴더에 백업**합니다(최근 30개). [파일 → 지금 백업]으로 언제든 백업할 수 있습니다. 프로그램을 지우거나 컴퓨터를 바꿀 때는 그 폴더의 가장 새 파일을 [파일 → 작품 되살리기]로 불러오세요.

맥에서 처음 백업할 때 "'사각-집필'이(가) 문서 폴더의 파일에 접근하려고 합니다"가 뜨면 **[허용]** 을 누르세요. 막으면 자동 백업만 되지 않고 집필은 그대로 됩니다(시스템 설정 → 개인정보 보호 및 보안 → 파일 및 폴더에서 다시 켤 수 있습니다).

## 알려진 제약

- 코드 서명이 없어 처음 한 번 위의 첫 실행 절차가 필요합니다.
- 업데이트 뒤 맥이 문서 폴더 접근 허용을 다시 물을 수 있습니다.
- 자동 백업은 켤 때, 메뉴 [사각-집필 종료 ⌘Q], 창 닫기에서 합니다. Dock 의 '종료'·로그아웃·강제 종료 때는 하지 않습니다(다음에 켤 때 백업합니다).
- 이 저장소에는 설치 파일만 올립니다. 소스 코드는 공개하지 않습니다.
